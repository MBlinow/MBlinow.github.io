# MBlinow.github.io
Personal page built using Jekyll TEST
https://github.com/jekyll/jekyll 




Setup:
Install Ruby:
    Windows:  Download and run the installer from rubyinstaller.org — grab the Ruby+Devkit version (the recommended one at the top). During install, keep the default options and let it run ridk install at the end (needed for native gems on Windows).
Install Bundler
    gem install bundler
Install dependencies:
(in repo) bundle install
Serve site:
    bundle exec jekyll serve
Open site:
    http://localhost:4000
